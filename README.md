# Vivek Biswas — Portfolio

A lightweight, responsive GitHub Pages portfolio inspired by the information architecture and editorial/minimal visual language of Yan Holtz's portfolio: oversized hero typography, short service sections, project filters, selected work, journey timeline and a clear contact section.

## Publish on GitHub Pages

1. Create a new GitHub repository (for example `vivekbiswas.github.io` or `portfolio`).
2. Upload **everything inside this folder** to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)` and save.
6. GitHub will provide the live URL.

## Before publishing

Edit these placeholders in `index.html`:

- `https://github.com/` → your GitHub profile/repository
- `https://www.linkedin.com/` → your LinkedIn profile
- `YOUR_EMAIL@example.com` → your professional email
- `https://www.upwork.com/` → your Upwork profile

You can also change the project descriptions as your 10-month journey progresses.

## Notes

The spreadsheet preview images were generated from the uploaded workbook files for use as portfolio thumbnails. The source workbooks are not included in the site because this is intended to be a public portfolio; add public download/demo links only if you want clients to access the actual files.
